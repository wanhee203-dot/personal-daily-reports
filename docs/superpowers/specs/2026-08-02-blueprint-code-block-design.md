# 蓝图代码块样式设计

- 日期：2026-08-02
- 状态：用户已确认
- 基础分支：`codex/daily-report-generator`

## 1. 目标

统一长海报 PDF 中所有围栏代码块的视觉样式，提高普通代码和长树形流程的可读性，同时避免居中规则破坏树形缩进。

## 2. 已确认的视觉方案

所有围栏代码块采用浅蓝“蓝图卡片”样式：

- 浅蓝背景、蓝色细边框和 12px 圆角；
- 代码字号保持 16px；
- 首选字体为本机已安装的 `Cascadia Mono`；
- 字体回退顺序为 `Cascadia Mono`、`Consolas`、`Microsoft YaHei`、`monospace`；
- 整组代码内容位于卡片中央；
- 代码组内部始终左对齐，原始空格、竖线和树形层级保持不变；
- 内容超出可用宽度时才允许换行，正常宽度内不得改变树形结构。

“整组居中”不等于“逐行居中”。实现不得给代码文本设置 `text-align: center`。

## 3. 流程标签规则

只有语言标记为 `text` 的围栏代码块显示 `CORE WORKFLOW` 标签，例如：

````markdown
```text
Mac: VS Code / Codex
        |
        v
Research Literature MCP
```
````

TOML、JSON、Shell 和未注明语言的普通代码块使用同一蓝图卡片，但不显示标签。语言判断不区分大小写；未知语言按普通代码块处理。

## 4. 组件与样式边界

`MarkdownContent` 根据代码块的 `language` 为围栏代码块提供明确的普通或流程变体。流程标签作为可见内容由组件输出，不依赖 Markdown 原文，也不修改源日报。

`poster.css` 负责：

- 蓝图卡片的背景、边框、圆角和间距；
- 代码组的整体居中；
- 代码文本内部左对齐；
- `Cascadia Mono` 字体与回退字体；
- 流程标签的胶囊样式；
- 长内容的安全换行和防裁切。

本次不自动识别四空格缩进内容，也不改变 Markdown 解析规则。只有围栏代码块进入新样式。

## 5. 数据流与兼容性

Markdown 解析结果继续提供现有的 `type: "code"`、`language` 和 `code` 字段。渲染组件只根据 `language` 选择视觉变体，PDF 尺寸计算、输出路径和文件命名均保持不变。

缺少语言或语言未知时不报错，直接渲染为无标签的普通蓝图代码块。现有日报内容不被程序改写。

## 6. 验证

自动验证至少覆盖：

- `text` 代码块获得流程变体并显示 `CORE WORKFLOW`；
- 普通代码块不显示流程标签；
- 代码文本的计算样式为左对齐并优先使用 `Cascadia Mono`；
- 代码组整体位于卡片中央，视觉快照中树形缩进未被破坏；
- 完整单元测试、端到端测试和 TypeScript/Vite 构建通过。

视觉基线更新后检查浅蓝背景、标签位置、代码可读性、树形缩进、换行和裁切。

## 7. 非目标

本次不安装字体、不下载 Web 字体、不修改日报 Markdown、不自动把缩进段落转换为代码块，也不改变普通正文、标题、行内代码或 PDF 输出规则。
