今日继续推进个人日报的可视化输出，新增 PDF 海报生成部分，并完成从 Markdown 日报到可视化成果的自动化处理。

当前可通过以下命令运行日报生成程序：

```powershell
npm.cmd run report -- "daily\2026-08\2026-08-01.md"
```

该命令以指定的 Markdown 日报为输入，执行项目中定义的 `report` 脚本，自动完成日报内容读取、版式生成及 PDF 海报输出。

目前已初步形成：

```text
Markdown 日报
    ↓
npm report 脚本
    ↓
内容解析与模板排版
    ↓
可视化日报
    ↓
PDF 海报输出
```

## 四、VS Code 图形化 Git 与 GitHub 上传流程

今日在 VS Code 中使用图形界面完成 Git 提交与 GitHub 远程仓库上传，并进一步理解了 Git 文件流转过程：

```text
工作区
    ↓ 暂存
暂存区
    ↓ 提交
本地 Git 仓库
    ↓ 推送
远程 GitHub 仓库
```

其中：

- 工作区保存当前实际修改的文件；
- 暂存区用于选择本次准备提交的修改；
- Commit 将暂存区内容写入本地 Git 仓库；
- Push 将本地提交上传至 GitHub 远程仓库；
- Pull 用于获取并合并远程仓库中的最新内容。

同时启用了 SSH 方式连接 GitHub。配置时将本地生成的 SSH 公钥上传至 GitHub，而私钥仅保留在本地电脑中。连接时，GitHub 使用已登记的公钥验证本地私钥产生的签名；验证成功后即可完成身份认证，不需要像 HTTPS 方式一样重复输入账号或访问令牌。
