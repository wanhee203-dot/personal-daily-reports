# 2026年7月28日日报

## 一、酸蚀程序 HC 复现

今日继续推进酸蚀程序 HC 的复现工作，已完成：

- 计算模型的网格搭建；
- 部分前处理程序的修改与适配；
- 初步检查网格生成结果及局部加密方案。

当前需要进一步确认：

1. 现有网格数量是否合理，是否会造成计算量过大；
2. 当前网格尺寸能否满足酸蚀区域的计算精度要求；
3. 是否可以采用“远场粗网格、重点区域局部加密”的方式，在保证计算精度的同时降低整体计算成本；
4. 后续需结合网格无关性分析，比较不同网格密度下的关键计算结果。

## 二、Samsung Finance Analysis V0

已完成 Samsung Finance Analysis 的 V0 版本，实现了对微信和支付宝通知消息的读取。

测试过程中发现以下问题：

- 当前程序会读取多种无关通知，尚未准确筛选出微信和支付宝的金融交易消息，拟通过应用来源、通知标题、关键词和消息格式进行过滤；
- 微信和支付宝的部分转账、红包记录不会产生可读取的系统通知，因此暂时无法通过现有通知监听方式获取；
- 后续需要进一步研究无通知交易的补充获取方式，并完善消息分类、去重和异常处理逻辑。

## 三、个人本地科研工作流

正在搭建个人本地科研工作流，目前已完成：

- 相关 API 的初步部署；
- 科研数据流与系统结构的设计；
- 文献发现、全文获取、PDF 解析和研究分析等模块的总体规划。

拟定的核心流程为：

```text
VS Code / Codex
        │
        │ MCP
        ▼
Research Literature MCP Server
        │
        ├── 文献发现
        │     ├── Web of Science Starter API
        │     ├── Crossref
        │     └── OpenAlex
        │
        ├── 全文定位
        │     ├── Unpaywall
        │     ├── CORE
        │     └── 出版社或机构仓储链接
        │
        ├── 校园网获取文献 PDF
        │
        ├── PDF 解析
        │     ├── 章节识别
        │     ├── 段落提取
        │     ├── 图表及公式定位
        │     └── 参考文献解析
        │
        └── 研究分析
              ├── 单篇论文分析
              ├── 多论文比较
              ├── 研究方向归纳
              └── 研究空白识别
```

最终希望从文献中结构化提取以下内容：

- 作者的主要观点与创新；
- 研究数据、理论模型和数值方法；
- 采用的评价指标与验证体系；
- 研究结论及适用范围；
- 现有研究的局限性；
- 不同论文之间的共性、差异和发展脉络。

在完成文献分类与综合总结后，进一步识别研究空白，并为个人研究方向及创新点的提出提供依据。
