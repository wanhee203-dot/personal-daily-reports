## 二、Samsung Finance Analysis V1

今日已完成 Samsung Finance Analysis 的 V1 版本，并完成主要数据采集、账单导入、交易合并、人工复核及调试功能。

目前 App 已实现：

- 监听并识别已验证的微信支付通知，自动记录交易金额和时间，同时过滤普通微信聊天通知；
- 导入微信官方 XLSX 账单和支付宝官方 CSV 账单；
- 支持账单预览、确认导入、批次统计和重复导入提示；
- 保存完整的 Raw Evidence，并生成统一格式的 Canonical Transaction；
- 所有金额均以整数“分”为单位保存，避免浮点数造成的金额误差；
- 自动合并同一笔微信支付通知和微信官方账单记录，同时保留两份来源证据；
- 对无法安全自动合并的交易提供 Review Inbox，支持人工确认合并或永久拒绝；
- 在 Debug 页面查看 Raw Events、Canonical Transactions、Evidence 数量、导入批次及对账状态；
- 完成 Room 数据库迁移、后台处理逻辑、自动化测试和 Samsung 真机验证。

当前尚未实现：

- 微信红包通知识别；
- 微信转账通知识别；
- 支付宝通知识别；
- SJTU 相关数据接入；
- 正式首页和统计分析功能；
- 地图功能；
- LLM 辅助分析；
- 云同步功能。

当前 V1 版本已经具备较完整的本地交易证据采集、账单导入、交易标准化、自动去重和人工复核能力。后续将继续完善通知识别范围，并逐步开发正式交互界面和统计分析功能。

## 三、个人本地科研工作流

个人本地科研工作流今日尚未进一步推进，当前继续沿用此前已经完成的基础工作和总体设计。

目前已完成：

- 相关 API 的初步部署；
- 科研数据流与系统结构的设计；
- Mac 与学校 Windows 主机之间的远程连接；
- Mac 本地 MCP 工具的初步编写；
- 文献发现、全文获取、PDF 解析和研究分析等模块的总体规划。

当前计划在 Mac 和学校 Windows 主机上部署相互协同的科研工作流。其中，Mac 主要负责 VS Code、Codex、本地 MCP 工具调用和研究任务调度；学校 Windows 主机主要负责利用校园网访问学校订阅资源、获取文献全文，并在必要时运行 Windows 端科研软件。

拟定的核心流程为：

```text
Mac：VS Code / Codex
        │
        │ MCP
        ▼
Mac 本地 Research Literature MCP Server
        │
        ├── 文献发现
        │     ├── Web of Science Starter API
        │     ├── Crossref
        │     └── OpenAlex
        │
        ├── 全文定位
        │     ├── Unpaywall
        │     ├── CORE
        │     └── 出版社或机构仓储链接
        │
        ├── 学校 Windows 主机
        │     ├── 利用校园网访问学校订阅资源
        │     ├── 获取文献全文 PDF
        │     ├── 执行 Windows 端科研任务
        │     └── 返回 PDF、日志及处理结果
        │
        ├── 本地文献库
        │     ├── 用户下载的 PDF
        │     ├── 文献元数据
        │     └── 分析结果
        │
        ├── PDF 解析
        │     ├── 章节识别
        │     ├── 段落提取
        │     ├── 图表及公式定位
        │     └── 参考文献解析
        │
        └── 研究分析
              ├── 单篇论文分析
              ├── 多论文比较
              ├── 研究方向归纳
              └── 研究空白识别
```

最终希望从文献中结构化提取以下内容：

- 作者的主要观点与创新；
- 研究数据、理论模型和数值方法；
- 采用的评价指标与验证体系；
- 研究结论及适用范围；
- 现有研究的局限性；
- 不同论文之间的共性、差异和发展脉络。

在完成文献分类与综合总结后，进一步识别研究空白，并为个人研究方向及创新点的提出提供依据。
